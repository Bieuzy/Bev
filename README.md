# Bev

Diffusion radio broadcast (Internet, FM, DAB+, enregistrement), pensée pour les radios associatives.

## Télécharger
Page de téléchargement : **https://bieuzy.github.io/Bev/**

Onglet **Releases** de ce dépôt : `Bev-Setup-x.y.z.exe` (installateur Windows : menu Démarrer, raccourci, désinstallation, mises à jour depuis l'appli) ou `Bev-macOS.dmg` (Mac à puce Apple).

Premier lancement sur Mac : clic droit sur Bev > **Ouvrir** (l'application n'est pas signée par Apple).
Sous Windows, si SmartScreen s'affiche : **Informations complémentaires** > **Exécuter quand même**.

## Mises à jour
Bev vérifie lui-même les nouvelles versions publiées ici. La plupart s'installent **en express** : quelques secondes, sans installateur ni droits administrateur, après vérification de l'empreinte. Quand une version change les bibliothèques de Bev, il propose l'installateur complet.

## Un problème, une idée ?
Dans Bev : **Signaler un problème** (Réglages, À propos ou journal) prépare un rapport sans mot de passe ni donnée personnelle. Ou directement : onglet **Issues** de ce dépôt.

Une faille de sécurité ? Merci de ne pas la publier dans une issue : utilisez « Report a vulnerability » (onglet Security du dépôt).
